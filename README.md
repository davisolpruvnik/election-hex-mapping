# Election Hex Mapping Guide
***As used in the election results section of Better Infanta***

This repository includes:
- `notebook`: Exploratory data analysis and visual construction to ensure fidelity to the final section.
  - `map.py`: Guide for precinct-level voter turnout mapping.
  - `mayoral.py`: Guide for mapping mayoral election winners and victory margins per precinct.
- `output`: Visualizations and figures generated from the notebooks.
- `utils`: Calculation scripts used in the main [BetterInfanta](https://github.com/davisolpruvnik/better-infanta) project.
